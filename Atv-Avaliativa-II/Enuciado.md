# Atividade Avaliativa II

Elabore um tema a sua escolha para criar um diagrama de caso de uso
Requisitos para o Diagrama:

    4 atores
    devem existir associações dos tipos (generalização, extends e include)
    no mínimo 10 casos de uso
    Não esqueça de numerar os casos de uso UC1, UC2.....
    deve ser feito usando plantUML

Após criar o diagrama deverá ser criado o documento de caso de uso

O documento pode ser criado usando editor de texto ou o notion. Caso use notion exporte em pdf para enviar.

escolha 5 casos de uso que você criou para documentar
Use a estrutura do documento visto em aula 

| Campos | Função |
|--------|--------|
| Nome | Nome do caso de uso |
| Objetivo | O que ele faz |
| Atores | Quem participa |
| Pré-condições | O que precisa existir antes |
| Pós-condições | O que fica pronto depois |
| Fluxo Principal | Caminho normal |
| Fluxos Alternativos | Caminhos Opcionais |
| Fluxos de Exceções | Erros/Problemas |
| Regras de Negócio | Restrições Importantes |
